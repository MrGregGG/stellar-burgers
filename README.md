# Stellar Burger

Учебный проект Яндекс Практикума. Приложение космической бургерной.

В этой версии подготовлены основные компоненты интерфейса и функции для работы с сервером. Основная задача проекта — добавить маршрутизацию, управление данными и авторизацию пользователей.

## Что нужно сделать

- Настроить переходы между страницами.
- Подключить Redux для работы с данными.
- Реализовать получение ингредиентов и работу конструктора.
- Добавить регистрацию и авторизацию.
- Настроить защищённые страницы.

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Откройте http://localhost:4000.

## API

Для запросов к серверу используется переменная `BURGER_API_URL`. Её адрес указан в файле `.env.example`.
