# Stellar Burger

Stellar Burger — учебное приложение космической бургерной, разработанное на React и TypeScript.

Пользователь может собрать бургер из предложенных ингредиентов, оформить заказ, посмотреть общую ленту заказов и управлять своим профилем.

## Запуск проекта

Требуется Node.js 22 или новее.

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Откройте http://localhost:4000.

Для остановки сервера нажмите `Ctrl + C`.

## Что реализовано

- Загрузка ингредиентов и разделение по категориям.
- Сборка бургера: добавление, удаление и перемещение ингредиентов.
- Выбор булки и автоматический подсчёт стоимости.
- Регистрация, вход и выход из аккаунта.
- Восстановление пароля.
- Личный кабинет и редактирование профиля.
- Создание заказов.
- Общая лента и история заказов пользователя.
- Просмотр подробной информации об ингредиентах и заказах.
- Защищённые маршруты и модальные окна.
- Обработка ошибок и состояний загрузки.

## Проверка проекта

Для проверки TypeScript:

```bash
npm run typecheck
```

Для проверки ESLint:

```bash
npm run lint
```

Для запуска тестов:

```bash
npm test
```

Для production-сборки:

```bash
npm run build
```

Дополнительные браузерные тесты:

```bash
npx playwright install chromium --only-shell
npm run test:browser
```

Браузерные тесты используют тестовые ответы API. При обычном запуске приложение обращается к настоящему серверу.

## API

Адрес сервера указан в `.env.example` в переменной `BURGER_API_URL`.

Для работы с реальными данными необходимо подключение к серверу API Яндекс Практикума.

## Структура проекта

- `src/components` — компоненты интерфейса.
- `src/pages` — страницы приложения.
- `src/services` — Redux и управление состоянием.
- `src/utils` — запросы к API и вспомогательные функции.
- `tests` — браузерные тесты.
