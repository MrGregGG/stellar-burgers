# Проект №4 — Stellar Burger

Учебный проект Яндекс Практикума. Приложение космической бургерной на React и TypeScript.

## Что добавлено по сравнению с main

- Настроена навигация между страницами с помощью React Router.
- Подключён Redux Toolkit для управления данными приложения.
- Реализован конструктор бургера: добавление, удаление и перемещение ингредиентов.
- Добавлен выбор булки и автоматический расчёт стоимости.
- Реализованы регистрация, авторизация и восстановление пароля.
- Добавлен личный кабинет с возможностью редактирования профиля.
- Реализовано оформление заказов.
- Добавлены общая лента заказов и история заказов пользователя.
- Добавлены защищённые страницы и модальные окна.
- Реализована обработка ошибок и состояний загрузки.

## Запуск проекта

Требуется Node.js 22 или новее.

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Откройте в браузере: http://localhost:4000
